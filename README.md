## Visualizador de Arquivos e Diretorios

### Funcionalidades:
* Lista arquivos e diretorios
* Visualiza conteudo de arquivos de texto
* Previsualiza Imagens PNG, JPG e JPEG
* Navega usando caminho de URL


### Rodando:

```shell
php -S localhost:8080 index.php
```
### Então acesse:
```
http://localhost:8080/
```
A aplicação funciona diretamente com o servidor de arquivos, entao deveria ser usado em ambiente local/confiavel
